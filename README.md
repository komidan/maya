# Example Build Configuration File
Keep in mind as you read through this example `Maya.toml` configuration file- things are subject to change, additions will be made over time.

```toml
# This might not have much purpose...
[project]
name = "maya"
author = "komidan"
version = "0.1.0"

# This is the default build/compilation flags to supply.
#   These fields are supplied to both `--debug` and `--release` sub-build
#   modes. It specifies things that you will adhere to outside of separate
#   compilation modes.
[build]
compiler = "gcc" # clang, msvc, gcc
standard = "c99" # c89, c99, c11, c17, c23
# List of [warnings](https://gcc.gnu.org/onlinedocs/gcc-14.2.0/gcc/Warning-Options.html#index-Wno-unused-parameter)
warnings = ["all", "extra", "pedantic", "error"]

# You can use these to add other arguments to GCC that don't have explicit
# customization fields. (Might change)
cflags = []
ldflags = []
libraries = []

# These are sane *defaults* I chose for project structure. This does _not_ need
# to be written in each config file unless you want something different.
[paths]
source = "src"  # Contains all personal project source files.
build = "build" # Contains all files generated by Maya for compilation.
binary = "bin"  # Contains the final executable binary after compilation.
library = "lib" # Contains third-party included libraries (e.x. Raylib)

# This field allows you to specify custom flags to use only under `--debug`
# compilation mode.
[build.debug]
cflags = ["-g", "-O0", "-DDEBUG"]

# This field allows you to specify custom flags to use only under `--release`
# compilation mode.
[build.release]
cflags = ["-O2", "-DNDEBUG"]

# I'm still considering this section, is it required or not... what would then
# be the default actions if not required?
[[target]]
name = "maya"
type = "exe"
source = "src"
```
